 📖 À propos du projet

L'objectif de ce projet est de fournir à la marque Nostopp une plateforme e-commerce totalement personnalisée, performante et indépendante. Contrairement à des solutions comme Shopify, cette application "from scratch" permet un contrôle total sur le design ("Shop the look", collections mises en avant) et sur la gestion interne (commandes, produits, clients).

 ✨ Fonctionnalités Principales

 🛒 Expérience Client (Vitrine Nostopp)
- Catalogue Dynamique : Navigation par catégories, collections en vedette (Feature Collections) et "Shop the look".
- Comptes Clients : Inscription, connexion et gestion du profil.
- Ajout au Panier et Paiement : Expérience fluide pour l'achat de vêtements/accessoires (selon ce que vend la marque).
- Responsive Design : L'interface est pensée pour être aussi belle et rapide sur mobile que sur ordinateur.

 ⚙️ Espace Administration (Tableau de Bord Marque)
- Gestion des Produits : Ajout, modification, gestion des images depuis une interface privée (`/admin/products`).
- Gestion des Commandes : Suivi du statut des commandes envoyées par les clients (`/admin/orders`).
- Gestion des Clients : Répertoire complet des clients inscrits (`/admin/clients`).

 🛠️ Stack Technique

Ce projet a été construit avec les technologies Web les plus modernes pour garantir de la rapidité, du SEO (référencement) et une maintenance facile au fur et à mesure que la marque grandira :

- Framework : Next.js (App Router)
- Langage principal : TypeScript
- Style Visuel : Tailwind CSS (ou autre selon ce que tu as utilisé)
- Base de données : MySQL
